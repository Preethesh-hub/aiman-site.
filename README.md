# For Aiman — A Digital Love Surprise ❤️

A single-file, mobile-first interactive love experience crafted with HTML5, CSS3, and Vanilla JavaScript.

## ✨ Features
- **Hero Reveal**: Ambient animations, glowing heart button, personalized typography.
- **Memories**: 3D flip cards sharing treasured moments.
- **Heartbeat Sync**: Real-time holding sensor with synchronized live ECG graph and haptics.
- **Make a Wish**: Interactive flickering candle with extinguishing smoke animation and sparkles.
- **The Question**: Playful interactive arena with dodging response and heart burst.
- **Wax Sealed Letter**: Unseal Sallu's letter with typewriter animation, interactive emoji reactions, and a milestone receipt.
- **Sound**: Dreamy Web Audio API chord synthesis (zero external audio files).
- **Themes**: Instant toggle between Sunset Rose and Midnight Plum.

## 🚀 Deployment
Deployable with zero configuration directly on **Vercel**, **Netlify**, or **GitHub Pages**.
